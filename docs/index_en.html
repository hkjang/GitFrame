QUICK START

Get Started with GitFrame in 3 Minutes

Easy commands and YAML configuration guide you can apply to existing projects right away.

1. Initialize GitFrame in an Existing Web Project

1. Initialize GitFrame in your project

Terminal 
cd /path/to/my-web-project
npx gitframe init

Running this command automatically generates default sample files `.gitframe/gitframe.yaml` and `.gitframe/demo.yaml`.

2. Project Configuration File (.gitframe/gitframe.yaml)

2. Configure (.gitframe/gitframe.yaml)

.gitframe/gitframe.yaml 
project:
  language: "go"         # node | python | go | java | compose | static
  install: "go mod download"
  build: "go build -o server ./cmd/app"
  start: "./server"
  port: 8080
scenarioFile: ".gitframe/demo.yaml"
outputDir: "output"
video:
  width: 1440
  height: 900
  fps: 30
intro:
  title: "My Web Application"
  subtitle: "Automated Demo Video"
  duration: 3
captions: true

3. Browser Test Scenario Definition (.gitframe/demo.yaml)

3. Define Scenario (.gitframe/demo.yaml)

.gitframe/demo.yaml 
start_url: "http://localhost:8080"
steps:
  - id: step-1
    action: goto
    url: "/dashboard"
    caption: "Navigate to main dashboard"

  - id: step-2
    action: pause
    milliseconds: 3000

  - id: step-3
    action: click
    selector:
      role: "button"
      name: "Load Data"
    caption: "Click the load data button"

  - id: step-4
    action: screenshot
    name: "dashboard_loaded"
    caption: "Dashboard verification complete"

4. Run Video Pipeline

4. Execute Video Pipeline

Terminal 
npx gitframe render --output output

✔ After rendering, check *.mp4, subtitles.srt, and report.html results in the output/ folder.
